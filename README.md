# University Exam Portal

## Project Overview

University Exam Portal is a web-based application developed using Django that allows students to securely log in and submit examination registration forms online.

The system simplifies examination registration by storing student details in a centralized database and providing a structured workflow for form submission.

---

## Features

- Student Login Authentication
- Secure Dashboard Access
- Examination Form Submission
- Database Storage using SQLite
- Success Confirmation Page
- Session-Based Authentication
- User-Friendly Interface

## Workflow

1. User opens login page.
2. User enters credentials.
3. Django authenticates user.
4. User is redirected to dashboard.
5. User accesses examination form.
6. User fills required details.
7. Data is submitted.
8. Information is stored in SQLite database.
9. Success page is displayed.
